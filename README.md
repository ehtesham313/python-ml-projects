# Machine Learning Applications Suite 🤖

A unified Streamlit web dashboard and collection of Machine Learning applications built with Python, Scikit-Learn, and NLP.

## 🚀 Applications Included

1. 🏏 **Cricket Score Predictor**
   - Predicts estimated final innings score based on overs played, wickets lost, run rate, venue, and pitch conditions.
   
2. 🩺 **Diabetes Risk & AI Awareness Hub**
   - Clinical risk predictor based on health metrics (glucose, BMI, age, insulin, blood pressure).
   - Includes an interactive AI chat assistant for diabetes symptoms, diet, and prevention advice.

3. 📧 **Email Spam Detector**
   - NLP-powered text classification model to distinguish between Spam and Legitimate (Ham) emails using TF-IDF vectorization.

---

## 💻 How to Run

### Run Main Dashboard
Launch all applications in a single unified interface:
```bash
streamlit run app.py
```

### Run Individual Programs
- **Cricket Score Predictor**: `streamlit run cricket.py` (or double-click `run_cricket.bat`)
- **Diabetes Hub**: `streamlit run diabetes.py` (or double-click `run_diabetes.bat`)
- **Email Spam Detector**: `streamlit run email_spam.py` (or double-click `run_email_spam.bat`)
